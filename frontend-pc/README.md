# PC 端进销存工作台

独立的 Vue 3 + Vite 桌面端前端，复用现有 FastAPI 接口、权限、数据范围和业务流转。左侧导航按账号权限显示，并按“现场作业 / 查询与协同 / 系统管理”分组；分组可收起，桌面侧栏还可收缩为图标栏。登录用户信息固定在侧栏底部的“我的账号”按钮中，点击后显示岗位、授权地点、个人设置、管理入口和退出登录。

已覆盖采购入库、装托盘、装箱、发运出库、接收验收、门店调拨、销售、销售退回、维修、盘点、IMEI 查询、库存、单据、离线草稿、用户/角色/组织/地点管理、审计和个人资料。按照当前岗位分工，深圳综合作业员在同一入口依次完成“收购验收 → 装入托盘 → 装箱封存”（先扫目标容器码，再批量扫手机/托盘）；加纳综合作业员在同一入口依次承接“到货拆箱/逐台验收 → 仓库拣货调拨 → 退回接收分诊 → 维修建单/QA”，步骤按权限显示并保留独立业务单据。深圳发运员、门店岗位和维修技师仍使用各自独立入口。

```bash
cd /Users/jackbond/Desktop/ghana_phone_mgmt/frontend-pc
npm install
npm run dev
```

默认地址：`http://127.0.0.1:5174`。扫码枪按键盘输入设备使用：选择地点/目标地点后页面会自动把光标移到下一项；将光标放在扫码输入框，扫码枪通常会自动发送 Enter；在装托/装箱步骤先扫描目标容器码，再连续扫描 IMEI/托盘。维修建单的关联退回单号可留空，调拨收货需明确选择“暂存已收”或“完成本次收货”。页面采用 `100dvh` 工作区，浏览器主体不纵向滚动；库存、单据、草稿和管理长列表在卡片内滚动并保留分页/固定表头，详情使用右侧固定抽屉。常见笔记本高度会自动隐藏重复说明、压缩步骤导航，优先把地点选择、扫码框和提交栏留在首屏；宽屏内容最大约 1440px，不强行铺满。生产部署时可通过 `VITE_API_BASE_URL` 指向后端 API。
