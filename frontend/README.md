# Frontend PWA

```bash
npm install
npm run dev
```

当前页面是手机端工作台，已配置 PWA Manifest 和 Service Worker。生产部署必须使用 HTTPS。

生产构建会输出 `manifest.webmanifest` 和 `sw.js`，在支持 PWA 的浏览器中可安装到手机桌面并以 standalone 模式启动；iPhone Safari 可使用“添加到主屏幕”。摄像头权限仅在员工进入扫码任务并点击后申请，无法使用摄像头时保留手工输入路径。

当前已接入手机号密码登录、验证码登录入口、`/auth/me` 权限过滤、摄像头连续扫码、手工输入降级、在线状态和 PWA 安装提示；采购入库、装托盘、装箱、发运、接收验收、调拨收发、销售、退回、维修、盘点、盘点差异审核和 IMEI 查询均连接后端接口。库存变更请求自动携带任务级幂等键；离线草稿保存完整表单快照，可在单据中心逐条或批量重试，冲突草稿保留不自动覆盖。验证码登录仍等待短信运营商适配器。
